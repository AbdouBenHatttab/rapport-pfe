\ReportSection{Introduction}{Introduction}

{\fontsize{12}{18}\selectfont
\setlength{\parindent}{1.2cm}
\setlength{\parskip}{6pt}

\indent This chapter focuses on Release 1, which forms the functional and technical foundation of the ArabSoft internal platform.
Through its use case diagrams, system sequence diagrams, state diagrams, class diagrams, and interface illustrations, this chapter presents how the first core functionalities of the platform are structured.
It highlights the implementation logic of secure access management and the first complete administrative workflow.
More specifically, Release 1 covers user registration, authentication, role assignment, account control, and leave request management.
Together, these elements establish the first operational base of the platform for employees, team leaders, and HR managers.

}

\ReportSection{II. Sprint 1: Access and Account Management}{II. Sprint 1: Access and Account Management}

\ReportSubsection{II.1 Sprint Goal}{\hspace{0.5cm} 1. Sprint Goal}

{\fontsize{12}{18}\selectfont
\setlength{\parindent}{1.2cm}
\setlength{\parskip}{6pt}

\indent This first sprint aims to establish the technical and functional access foundation of the platform.
It implements the core access features: user registration, secure authentication, password reset, HR user account setup, role assignment with notification and email, account activation and deactivation, profile update, and access control.
It also introduces the restricted \textbf{NEW\_USER} state to control onboarding before HR validation.
The sprint is planned as a two-week iteration.
The objective is to obtain an operational base for the next functional developments of the platform.

}

\ReportSubsection{II.5 Sprint Review}{\hspace{0.5cm} 5. Sprint Review}

{\fontsize{12}{18}\selectfont
\setlength{\parindent}{1.2cm}
\setlength{\parskip}{6pt}

\indent Sprint 1 delivered the access foundation of the platform. It covered user registration, secure authentication, the \textbf{NEW\_USER} pending state, password reset, profile management, HR user account setup, role assignment notification and email, account activation and deactivation, and access control. This result provides the stable base required before implementing the next workflow.
}

\ReportSubsection{II.6 Sprint Retrospective}{\hspace{0.5cm} 6. Sprint Retrospective}

{\fontsize{12}{18}\selectfont
\setlength{\parindent}{1.2cm}
\setlength{\parskip}{6pt}

\indent The main positive point of Sprint 1 was the establishment of a coherent access-management base that connects authentication, user status, and HR account-control actions. The main difficulty was integrating Keycloak, the local database, role assignment, and account states in a consistent way. For the next sprint, the improvement point is to keep workflow validation and UI feedback consistent across all user actions.
}
